# No Flame & Smoke

**Version:** 1.2.2
**Minecraft:** 26.1.2 – 26.3
**Loader:** Fabric
**Environment:** Client-side
**License:** MIT

No Flame & Smoke lets you independently hide flame and smoke particles from selected Minecraft blocks.

## Features

* **Per-block controls:**

    * Torch
    * Wall Torch
    * Redstone Torch
    * Wall Redstone Torch
    * Soul Torch
    * Wall Soul Torch
    * Copper Torch
    * Wall Copper Torch
    * Candles
    * Furnace
    * Smoker
    * Blast Furnace

* **Per-effect control:** Flame and Smoke can be enabled or disabled independently for each supported block.

* **Global controls:** quickly enable or disable all flame or smoke particles.

* **Restore Vanilla:** reset particle settings to their vanilla state.

* **Mod Menu integration:** configuration screen available directly from Mod Menu.

* **Client-side only:** no server installation is required.

* **Persistent configuration:** settings are saved between game sessions.

> **ON** = particle visible
> **OFF** = particle hidden

## Supported Minecraft versions

The same No Flame & Smoke 1.2.2 JAR supports:

* Minecraft 26.1.2
* Minecraft 26.2
* Minecraft 26.3

## Installation

1. Install Fabric Loader for a supported Minecraft version.
2. Place `noflamesmoke-1.2.2.jar` in your `.minecraft/mods/` folder.
3. Install Mod Menu if you want to access the configuration screen directly from the Mods menu.
- Fabric Loader 0.19.3 or newer
- Fabric API
- Mod Menu (optional, for in-game configuration)
## Configuration

### In game

Open:

**Mod Menu → No Flame & Smoke → Configure**

### Configuration file

Settings are stored in:

`config/noflamesmoke.json`
